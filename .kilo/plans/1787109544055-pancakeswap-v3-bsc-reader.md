## Goal

- Renaming the directory itself.
- Updating README prose that mentions the package name (the README currently doesn't reference `robinhood-lp-position` as a package name — it only describes functionality).
- Renaming env vars (e.g. `RH_*`) — they're chain-specific, not package-specific.

1. **Edit `package.json`** — change the `"name"` field from `"robinhood-lp-position"` to `"lp-position-watcher"`.

3. **Verify** with `npm run typecheck` and `npm run build` (no behavioral change expected — the name field isn't read at runtime, but a fresh `npm install` will normalize the lockfile).
4. **Optional follow-up**: run `npm install` so the lockfile is rewritten cleanly. Not required for the rename itself; only needed if the user wants a guaranteed-consistent lockfile.
